**Judul :** Prediksi Kualitas Udara Menggunakan Model Regresi Berbasis Machine Learning

**Tujuan :** Proyek ini bertujuan untuk membangun model prediktif yang mampu memperkirakan tingkat kualitas udara (Air Quality Index/**AQI**) berdasarkan berbagai parameter polutan seperti PM2.5, PM10, NO₂, CO, dan O₃. Dengan pendekatan berbasis algoritma regresi machine learning, penelitian ini diharapkan dapat menghasilkan model dengan akurasi tinggi dalam memprediksi nilai AQI pada berbagai kondisi lingkungan. Selain itu, proyek ini bertujuan untuk membandingkan performa beberapa model regresi guna menentukan model terbaik dalam memprediksi data kualitas udara. Hasil perbandingan ini memberikan pemahaman yang lebih mendalam mengenai efektivitas masing-masing algoritma terhadap data lingkungan yang bersifat kompleks dan non-linear.

**How to run :**

* Jupyter Notebook utama proyek ini dapat diakses pada direktori: 

  Big-Data_Assignment/Code/UTS/.
* didalam folder tersebut dapat 3 jupyter notebook, yaitu:
  * Combine.ipynb
  * Kelompok11_Code.ipynb
  * Scraping.ipynb
* Notebook utama yang digunakan adalah Kelompok11_Code.ipynb. Notebook ini sudah mencakup hasil penggabungan data (Combine.ipynb) dan proses scraping dari Scraping.ipynb.
* Untuk menjalankan seluruh proses, buka notebook Kelompok11_Code.ipynb dan pilih menu Run All untuk mengeksekusi setiap sel secara berurutan.
* Pada bagian akhir notebook terdapat pengujian model prediksi menggunakan input dari pengguna serta data hasil scraping secara langsung.
* Dataset yang digunakan dapat ditemukan pada direktori:

  Big-Data_Assignment/Dataset/
* **Catatan**: Beberapa direktori memiliki subfolder bernama Old/, yang berisi dataset dan notebook versi lama sebelum dilakukan pembaruan.
